| Key          | Purpose                   | Example Meaning                        |
| ------------ | ------------------------- | -------------------------------------- |
| `imei`       | Unique ID of GPS device   | Identifies which tracker sent data     |
| `timestamp`  | Date & time of GPS record | When this location/status was recorded |
| `lat`        | Latitude                  | Vehicle north/south position           |
| `lng`        | Longitude                 | Vehicle east/west position             |
| `speed`      | Current speed             | Usually in KM/H                        |
| `heading`    | Direction vehicle moving  | 0-360 degrees                          |
| `battery`    | Device battery level      | Internal tracker battery percentage    |
| `ignition`   | Vehicle engine status     | `true` = ON, `false` = OFF             |
| `gsm_signal` | Mobile network strength   | SIM/network quality                    |
| `satellites` | GPS satellites connected  | GPS accuracy indicator                 |
| `odometer`   | Total traveled distance   | Usually meters or KM                   |
| `power_cut`  | Main power disconnected?  | Theft/tampering detection              |
